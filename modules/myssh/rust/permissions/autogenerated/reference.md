## Default Permission

Allows every MySSH plugin command.

#### This default permission set includes the following:

- `allow-list-hosts`
- `allow-create-host`
- `allow-update-host`
- `allow-delete-host`
- `allow-list-groups`
- `allow-create-group`
- `allow-delete-group`
- `allow-open-session`
- `allow-send-input`
- `allow-resize-session`
- `allow-close-session`
