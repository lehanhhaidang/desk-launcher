## Default Permission

Allows every Comtor plugin command.

#### This default permission set includes the following:

- `allow-list-projects`
- `allow-get-project`
- `allow-create-project`
- `allow-update-project`
- `allow-delete-project`
- `allow-list-meetings`
- `allow-list-recent-meetings`
- `allow-get-meeting`
- `allow-create-meeting`
- `allow-update-meeting`
- `allow-delete-meeting`
- `allow-save-transcript`
- `allow-save-audio`
- `allow-get-audio`
- `allow-delete-audio`
- `allow-audio-exists`
- `allow-get-settings`
- `allow-get-soniox-key`
- `allow-get-openai-key`
- `allow-set-soniox-key`
- `allow-set-openai-key`
- `allow-clear-soniox-key`
- `allow-clear-openai-key`
- `allow-get-prefs`
- `allow-set-prefs`
- `allow-export-xlsx`
