## Default Permission

Allows every Media Toolbox plugin command (Capture, Images, Videos).

#### This default permission set includes the following:

- `allow-video-info`
- `allow-video-download-start`
- `allow-video-download-cancel`
- `allow-video-download-read`
- `allow-video-download-cleanup`
- `allow-media-image-probe`
- `allow-media-image-read-bytes`
- `allow-media-image-process-start`
- `allow-media-image-process-cancel`
- `allow-media-image-process-cleanup`
- `allow-media-video-probe`
- `allow-media-video-process-start`
- `allow-media-video-process-cancel`
- `allow-media-video-process-cleanup`
