## Default Permission

Allows every Open Sesame plugin command.

#### This default permission set includes the following:

- `allow-auth-github-start`
- `allow-auth-github-poll`
- `allow-auth-list-accounts`
- `allow-auth-logout`
- `allow-workspace-list`
- `allow-workspace-create`
- `allow-workspace-update`
- `allow-workspace-delete`
- `allow-doc-set-detect-strategy`
- `allow-doc-set-create`
- `allow-doc-set-list`
- `allow-doc-set-list-all`
- `allow-doc-set-delete`
- `allow-doc-set-move`
- `allow-doc-set-set-auto-sync`
- `allow-doc-set-setup-github-remote`
- `allow-doc-set-import-from-github`
- `allow-doc-set-sources`
- `allow-doc-set-mapping-preflight`
- `allow-doc-set-set-source-mapping`
- `allow-doc-set-add-source`
- `allow-doc-set-add-mirror-source`
- `allow-doc-set-remove-new-mirror-path`
- `allow-doc-set-refresh-mirror`
- `allow-doc-set-restore-local-from-mirror`
- `allow-doc-set-keep-both-local-changes`
- `allow-doc-set-push-from-local`
- `allow-doc-set-pull-from-repo`
- `allow-doc-set-watch-start`
- `allow-doc-set-watch-stop`
- `allow-config-export`
- `allow-config-import`
- `allow-sync-up`
- `allow-sync-down`
- `allow-sync-force-push`
- `allow-sync-force-pull`
- `allow-sync-status`
- `allow-sync-logs`
- `allow-file-tree`
- `allow-file-content`
- `allow-file-search`
- `allow-file-toggle-bookmark`
- `allow-file-list-bookmarks`
- `allow-write-text-file`
- `allow-read-text-file`
