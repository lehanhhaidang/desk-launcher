## Default Permission

Allows every Port Killer plugin command.

#### This default permission set includes the following:

- `allow-list-ports`
- `allow-kill-ports`
- `allow-list-tunnels`
- `allow-create-tunnel`
- `allow-update-tunnel`
- `allow-delete-tunnel`
- `allow-start-tunnel`
- `allow-stop-tunnel`
- `allow-list-ssh-keys`
